- **Extraction can still return an empty card on its very first attempt for a section, even when the user gave real data** — reproduced repeatedly in `skills`/`languages` with `mistral-small`, especially when a closing phrase ("خلاص"/"مفيش") appears in the same message as the data or immediately after a short answer. Two proposed fixes to try next, not yet done: (1) run the extraction call on `mistral-large` while keeping the conversation call on `mistral-small` — extraction is short and mechanical, so the cost difference should be negligible, and a stronger model may simply not make this mistake; (2) always run extraction twice for array-shaped sections and take the union/larger result, rather than only retrying after an empty first attempt.
